# DayFlow V1 产品需求

DayFlow 是面向 Windows 10/11 个人用户的本地任务管理、工作记录与周期复盘应用。默认简体中文，不使用账号、服务器、AI API 或演示数据。

核心闭环：规划任务 → 小组件待办 → 完成后自动进入工作记录；临时完成或尚未完成的工作直接手动记录 → 根据当天实际工作和真实历史生成总结 → 退出重启后保留数据。

## 功能范围

- `main` 完整窗口：今日待办与今日工作记录、全部任务、工作记录、周期复盘、设置。
- `widget` 无标题栏置顶小组件：拖动、缩放、快速输入标题和可选日期/时间、完成、定位详情、展开、隐藏。
- `ball` 独立置顶悬浮球：小组件手动收起、点击展开、拖动、右键展开或隐藏；设置页两个显示开关互斥，展示状态跨启动记忆。
- 首次使用：仅新用户自动显示 8 步教程，完整介绍任务、记录、复盘、小组件、设置与备份；每步可跳过，完成或跳过后不再弹出，已有用户升级不弹出。
- 任务：标题必填（1–500 字），描述、截止日期/时刻、重要程度、状态、分类可编辑；所有新建入口默认截止日期为本地今天、具体时刻留空，允许修改或清空；明确保存；软删除与回收站恢复；历史事件与进展记录。
- 排序：逾期、今天、未来、无截止日期；再按截止时间、重要程度、创建时间；日期任务在当地次日零点后才逾期。
- 工作记录：默认查看今天，汇集只读的任务完成快照、手动已完成事项和工作进展；保留日期、全部日期与内容查询。手动记录支持内容、必填类型、归属本地日期、可选任务关联，以及新增、编辑、删除和历史补录。
- 总结：本地日报、周一至周日周报、自然月月报；正文和复制文本仅包含实际完成事项（任务完成和手动完成分别标明来源）、工作进展、下一周期需要完成的任务、未完成的任务四部分。下一周期分别为明天、下周、下一个自然月。
- 设置：3/5/8 条待办、背景透明度、窗口记忆、完成事项、三种主题、开机启动、关闭行为、完成动画、默认重要性、通知和勿扰、分类、JSON 导出、SQLite 备份与确认恢复。
- 系统：托盘、单实例、开机启动、一次性到期提醒；每天首次启动备份。

## 数据原则

任务状态是当前事实，完成事件是历史事实。重开、删除、改名不抹除完成成果，自动记录使用完成时的标题快照；之后转为待办或进行中标注重新开启，取消不算重开。同一任务同一天多次完成只展示最后一次，不同日期分别保留；原始事件完整保存。报表按周期内任务 ID 去重并采用最后一次完成快照。

手动记录分为 `completed`（已完成事项）和 `progress`（工作进展），按用户填写的本地日期归档，日内使用原始录入时间排序。关联任务不改变状态，自动和手动记录分别展示。工作记录页分别统计完成任务数、手动完成事项数、工作进展数，避免把进展算作成果。报表的未完成任务从周期末事件快照重建，包含当时全部未删除的待办和进行中任务，包括逾期、未来到期及无日期；下一周期任务为其中截止日期落入下周期的子集，两个栏目允许重复。未来周期的期末状态只能反映截至当前已发生的事件。

数据库当前版本为 3，删除旧窗口模式偏好；版本 2 将已有手动日志归为工作进展，保留原文并允许修改类型。恢复旧备份在临时副本完成迁移和验证，成功后备份并替换当前库，原备份不变。JSON 导出格式为版本 3。

## 小组件行为

小组件固定为始终置顶的独立窗口，显示在其他普通窗口上方。支持手动收起为悬浮球、点击球展开，以及隐藏后从主窗口或托盘恢复。设置页通过“显示小组件”“显示悬浮球”两个互斥开关反映实际展示状态，两个都关闭时完全隐藏。正常启动和开机启动记住上次展示状态；位置和尺寸遵循现有记忆设置。恢复旧备份不会恢复桌面模式。

范围以用户本次完整开发要求为准；不加入云同步、团队协作、AI 评分、重复任务等额外业务。
