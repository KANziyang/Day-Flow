# DayFlow V1 产品需求

DayFlow 是面向 Windows 10/11 个人用户的本地任务管理、工作记录与周期复盘应用。默认简体中文，不使用账号、服务器、AI API 或演示数据。

核心闭环：创建任务 → 小组件待办 → 标记完成 → 独立记录工作 → 根据真实历史生成总结 → 退出重启后保留数据。

## 功能范围

- `main` 完整窗口：今日任务、全部任务、工作日志、周期复盘、设置。
- `widget` 无标题栏小组件：拖动、缩放、快速输入标题和可选日期/时间、完成、定位详情、展开、隐藏、切换模式。
- 任务：标题必填（1–500 字），描述、截止日期/时刻、重要程度、状态、分类可编辑；明确保存；软删除与回收站恢复；历史事件与进展记录。
- 排序：逾期、今天、未来、无截止日期；再按截止时间、重要程度、创建时间；日期任务在当地次日零点后才逾期。
- 工作日志：内容、归属本地日期、可选任务关联；新增、编辑、删除、补录、日期/内容查询。
- 总结：本地日报、周一至周日周报、自然月月报；完成快照、工作日志、期末待办、下周到期、完成趋势与分类；复制文本。
- 设置：窗口模式、3/5/8 条待办、背景透明度、窗口记忆、完成事项、三种主题、开机启动、关闭行为、完成动画、默认重要性、通知和勿扰、分类、JSON 导出、SQLite 备份与确认恢复。
- 系统：托盘、单实例、开机启动、一次性到期提醒；每天首次启动备份。

## 数据原则

任务状态是当前事实，完成事件是历史事实。重开、删除、改名不抹除完成成果。完成任务按报告周期内的任务 ID 去重，同时公开完成事件总数。日志按用户填写的本地日期归档。周期末状态从事件快照重建；未来周期的期末状态只能反映截至当前已发生的事件。

## 桌面模式的边界

Windows Explorer 宿主适配独立封装。验证 WorkerW、窗口句柄与 DPI 上下文后才尝试挂载。任何前置条件不满足则显示“桌面兼容模式”及原因，使用普通非置顶窗口。真正挂载的多显示器、Explorer 重启与系统版本行为必须按设备验收，不将代码存在等同于验证通过。

范围以用户本次完整开发要求为准；不加入云同步、团队协作、AI 评分、重复任务等额外业务。
