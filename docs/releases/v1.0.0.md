# DayFlow V1.0.0（预发布）

DayFlow 是一款面向个人用户的 Windows 桌面任务管理、工作记录与周期复盘工具。

从计划任务、记录进展到完成事项、回顾工作，核心功能均在本地运行，无需账号，也不依赖 AI 服务。此版本作为 **Pre-release（预发布版本）** 提供试用与反馈。

## 主要功能

- **桌面任务小组件**：快速添加与完成任务，显示截止时间和逾期标记，支持展开主窗口、调整尺寸、记忆位置，以及普通非置顶与始终置顶切换。
- **完整任务管理**：支持描述、截止日期与可选时刻、重要程度、分类、四种任务状态、搜索和筛选；任务软删除后可恢复，重新开启不会抹掉历史完成事件。
- **独立工作日志**：无需先建任务即可记录实际工作，支持补录历史日期，也可关联任务记录进展。
- **日报、周报与月报**：根据实际完成事件和工作日志生成本地总结，支持历史日期、趋势统计与复制总结文本。
- **本地数据管理**：SQLite 持久化、自动与手动备份、备份恢复和 JSON 导出；主窗口与小组件同步更新。
- **桌面使用体验**：简体中文、浅色/深色/跟随系统主题、系统托盘、单实例运行和后台保留小组件。主窗口与设置页显示当前版本 `V1.0.0`。

## 下载与安装

在本页 **Assets** 中下载 `DayFlow_1.0.0_x64-setup.exe`，双击后按中文安装向导完成安装。

安装后可从桌面快捷方式或开始菜单启动，无需 Node.js、Rust 或命令行。当前已实测平台为 **Windows 11 x64**。

运行需要 WebView2；缺少该组件时，安装器会联网下载。安装完成后，任务、日志与报表等核心功能支持离线使用。

## 从旧版升级

1. 在 DayFlow 中选择“退出应用”；默认只关闭主窗口仍会保留后台进程。
2. 运行新版安装包，在升级页面选择“请勿卸载”，按原目录继续安装。
3. 安装器替换程序文件，原有任务和日志保存在独立的数据目录中；若选择先卸载，请勿勾选“删除应用数据”。

本次已在 Windows 11 实测从 `0.1.0` 覆盖升级至 `1.0.0`，升级前后任务、历史事件、工作日志及分类逐条一致。

数据目录通常为 `%APPDATA%\com.dayflow.desktop\`，也可在设置页查看。应用内提供数据库备份入口。

## 当前限制

- 安装包尚未代码签名。
- 本机使用明确标注的“桌面兼容模式”，实际行为为普通非置顶窗口；真正的桌面层嵌入尚未通过本机验收。始终置顶模式可单独切换。
- Windows 10、不同 DPI、多显示器、Explorer 重启恢复，以及通知与开机启动的完整实机验证仍待补充。
- 暂不支持自动检查更新、云同步、重复任务、AI 总结或 Markdown 文件导出；更新需手动安装新版 EXE。
