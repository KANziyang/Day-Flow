# DayFlow V1.0.1 测试版

修复 Windows 桌面模式的小组件层级和窗口生命周期问题，供 Windows 10 设备回归验证。

- 小组件挂到桌面图标视图的父宿主，位于图标之上，不再挂到图标后方的壁纸 WorkerW。
- 隐藏、恢复和模式切换保留桌面子窗口样式、位置及当前可见状态。
- 真正退出时先隐藏小组件并解除桌面挂载，再完成框架清理。

前端 6 项测试、Rust 17 项测试（含 3 项原生窗口回归）通过。Windows 10 的实际点击、输入、拖动、缩放、隐藏恢复、模式切换及退出残留仍需在问题设备复测，不能将自动化测试等同于实机验收。

安装包：`DayFlow_1.0.1_x64-setup.exe`。先在旧版选择“退出应用”，再运行安装包升级。任务与日志仍使用原应用数据目录；不要在卸载时选择删除应用数据。
