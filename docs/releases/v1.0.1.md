# DayFlow V1.0.1 测试版

更新日期：2026-10-17。本版包含桌面小组件修复、统一工作记录、周期报表简化和新建任务日期优化。

## 更新内容

- **桌面小组件**：修正桌面挂载层级，处理小组件落在桌面图标之下、无法点击或拖动的问题；完善隐藏、恢复和模式切换时的位置与可见状态保持，真正退出前先隐藏并解除桌面挂载。
- **统一工作记录**：“工作日志”更名为“工作记录”。任务完成后按实际完成日期自动进入记录，保留完成时的标题；临时成果可手动记录为“已完成事项”，未完成的工作可记录为“工作进展”。首页和历史记录统一展示三类内容，并分别统计。
- **历史保留**：任务改名、移入回收站或重新开启后，原完成记录仍保留；重新开启的任务标注“之后重新开启过”。同一任务同一天多次完成只展示最后一次快照，原始历史完整保留。手动记录支持修改类型、日期、内容和关联任务，关联不会改变任务状态。
- **四栏周期报表**：日、周、月报固定展示“实际完成事项”“工作进展”“下一周期需要完成的任务”“未完成的任务”。下一周期分别为明天、下周和下月，显示完整日期范围；任务显示截止日期、时刻或“无截止日期”。移除原统计卡片、趋势和分类汇总，页面正文与复制总结保持一致。
- **新建任务默认今天**：主窗口和小组件的快捷添加、完整新建表单均默认使用本地今天，时刻留空；支持手动修改或清空日期。快捷添加成功后恢复默认值，保存失败保留输入，已有任务的日期不受影响。

## 数据与升级

- 原任务、完成历史和手动日志继续保留。数据库自动升级为版本 2，旧手动日志统一归为“工作进展”，原文和时间保持完整，可之后逐条修改类型。
- 旧版和新版备份均可恢复：先在临时副本中升级并验证，再备份当前数据并替换；原备份文件保持完整。JSON 导出同步升级为版本 2，包含统一工作记录。
- 升级前可在设置中创建备份，再通过托盘“退出 DayFlow”或应用内“退出应用”真正退出，然后运行安装包覆盖升级。关闭主窗口可能只是隐藏到托盘；无需先卸载，如需卸载请勿选择删除应用数据。
