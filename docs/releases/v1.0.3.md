# DayFlow V1.0.3 测试版

更新日期：2026-10-17。本版新增悬浮球、两个显示开关和可跳过的首次使用教程。

## 更新内容

- **悬浮球**：小组件顶部可手动收起为置顶悬浮球，点击球展开；球支持拖动，右键菜单可展开或隐藏。展开位置跟随球，并保留小窗口尺寸。收起和隐藏保留本次运行中的未提交输入、任务列表展开及滚动状态。
- **两个显示开关**：设置页使用“显示小组件”“显示悬浮球”两个互斥开关，全部关闭时完全隐藏。顶部按钮、托盘及原生窗口操作会同步开关状态；正常启动和开机启动记住上次的展开、球或隐藏状态。
- **首次使用教程**：新用户首次创建数据库时显示 8 步教程，覆盖任务、工作记录、周期复盘、小组件与悬浮球、设置、备份和退出方式。每步可跳过，也可按 Esc 跳过，完成或跳过后不再自动弹出；已有用户升级不弹出。教程期间暂缓显示置顶小组件，结束后恢复，不向真实数据写入示例内容。
- **窗口尺寸与位置**：分别保存小窗口尺寸和球的位置，修正首次显示时多算 30 像素高度的问题；使用显示器工作区及物理坐标约束窗口边界。

## 数据与升级

- 数据库和 JSON 导出格式均保持版本 3，无新增数据库迁移。任务、工作记录、完成历史、分类、其他偏好及既有数据继续保留，支持恢复版本 1、2、3 的 SQLite 备份。
- 教程确认状态单独保存在本机数据目录，恢复数据库备份不会重置用户已经完成或跳过教程的决定。卸载后保留旧数据再安装时，按已有用户处理。
- 升级前可在设置中备份，通过“退出应用”或托盘“退出 DayFlow”真正退出，再运行新版安装包。安装器识别已有版本；选择不卸载并覆盖程序目录时保留独立数据目录，勿选择删除应用数据。
