# DayFlow V1.0.2 测试版

更新日期：2026-10-17。本版移除桌面模式，保留始终置顶的小窗口。

## 更新内容

- **小窗口固定置顶**：小组件作为独立窗口显示在其他普通窗口上方，不再挂载到 Windows 桌面或 Explorer。移除小窗口图钉、设置页和托盘中的模式切换入口。
- **保留小窗口功能**：快速添加任务、完成任务、展开主窗口、隐藏恢复、拖动缩放及位置记忆继续可用，主窗口与小窗口的数据同步保持正常。
- **修复重启后的尺寸变化**：调整无标题栏小窗口的尺寸恢复时机，避免重启后高度增加 30 像素；正常启动及开机启动均恢复原有位置、大小和置顶状态。
- **修复“查看其余任务”无反应**：点击后在小窗口内展开全部待办，并可点击“收起”恢复设置的 3/5/8 条显示数量。列表独立滚动，窗口大小和底部快捷添加保持稳定；完成任务后，待办数量与主窗口工作记录同步更新。

## 数据与升级

- 数据库自动升级为版本 3，仅清理旧窗口模式设置；任务、工作记录、完成历史、其他偏好与窗口位置继续保留。旧版手动日志仍按既有规则升级为工作进展。
- 支持恢复版本 1、2、3 的 SQLite 备份。旧备份先在临时副本中升级并验证，再备份当前数据并替换；原备份文件保持完整，恢复后小窗口始终置顶。JSON 导出格式同步为版本 3。
- 升级前可在设置中创建备份，通过托盘“退出 DayFlow”或应用内“退出应用”真正退出，再运行安装包覆盖升级。关闭主窗口可能只是隐藏到托盘；无需先卸载，如需卸载请勿选择删除应用数据。

## 验证情况

- 本版代码已通过前端 **19/19**、Rust **29/29** 自动化测试，覆盖旧数据库升级、旧备份恢复、数据保留及非法备份拒绝。版本更新后前端 19 项再次通过，TypeScript/Vite 构建及 Rust 格式检查通过。
- 本机已完成 **7 组**真实应用验证：独立置顶窗口属性、模式入口与接口移除、任务操作及双窗口同步、隐藏恢复、主窗口切换、开机启动参数下重启、位置和尺寸恢复；两次测试均通过应用自身退出命令结束，并确认进程退出。
- 针对“查看其余任务”追加 **8 组**真实窗口验证，覆盖 9 项任务显示 5 项再展开、滚动到底部、收起、3/5/8 条设置、完成与同步、打开详情、隐藏恢复及任务数量变化。展开/收起不切换主窗口页面，置顶属性及原生窗口尺寸保持不变；测试实例正常退出。
